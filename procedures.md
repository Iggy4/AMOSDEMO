# Synapse V1 Procedures

## Startup
1. Verify emergency stop is released.
2. Confirm guards and door interlocks are active.
3. Power on main machine switch.
4. Initialize CNC controller.
5. Home all axes.
6. Check coolant level and flow.
7. Load correct program.
8. Verify tool offsets and work offset.
9. Run dry cycle if required.

## Shutdown
1. Stop current job safely.
2. Return machine to home or safe position.
3. Turn off spindle.
4. Clean chips from enclosure and fixture.
5. Turn off coolant system.
6. Power down controller.
7. Shut off main power if required.

## Tool Change
1. Pause machine operation.
2. Move spindle to safe position.
3. Confirm correct replacement tool.
4. Remove current tool.
5. Insert and secure new tool.
6. Update tool number and offset.
7. Verify clearance.
8. Resume operation.

## Fixture Setup
1. Clean fixture surface.
2. Mount fixture securely.
3. Verify fixture alignment.
4. Tighten all bolts to shop standard.
5. Load part into fixture.
6. Check tool clearance.
7. Run dry test.
