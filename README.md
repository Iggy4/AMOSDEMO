# AOMS / Synapse V1 Interactive Website

Git-ready static site for demonstrating a Raspberry Pi-based machine monitoring system.

## Deploy
Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub repo, then enable GitHub Pages from `main` / root.

## Included
- Machine 1 online dashboard
- Green/yellow/red status states
- 3D-style machine + Synapse visual
- Cycle/startup/idle/vibration/temp measurables
- Instructions and safety notices
- Preventative maintenance panel
- V1 to V2 roadmap
